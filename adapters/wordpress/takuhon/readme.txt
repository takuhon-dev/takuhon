Host a self-hosted, portable takuhon profile on WordPress: edit your
takuhon.json and serve the public profile via a block and a REST API.

== Description ==

Takuhon is a self-hosted, portable profile/links site built around a canonical
takuhon.json. This plugin lets an existing WordPress site host a takuhon profile
without making WordPress the source of truth.

This is an early skeleton. Functionality is being added in stages; see the
project repository for status.

== Installation ==

1. Upload the plugin zip through Plugins > Add New > Upload Plugin, or extract it
   into wp-content/plugins/.
2. Activate the plugin through the Plugins screen.
