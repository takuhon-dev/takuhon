# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, which sets the expectations for behavior in our community.

The full text of the Code of Conduct is published by the Contributor Covenant project at:

> https://www.contributor-covenant.org/version/2/1/code_of_conduct/

By participating in this project — including issues, pull requests, discussions, and any project-related communication — you agree to abide by that Code of Conduct.

## Scope

This Code of Conduct applies within all project spaces, and also applies when an individual is officially representing the project or its community in public spaces.

## Enforcement

Instances of unacceptable behavior may be reported to the project maintainers by:

- Opening a private GitHub Security Advisory (preferred for sensitive reports): https://github.com/takuhon-dev/takuhon/security/advisories/new
- Or emailing the maintainers: **hello@takuhon.org**

All complaints will be reviewed and investigated promptly and fairly. Project maintainers are obligated to respect the privacy and security of the reporter.
